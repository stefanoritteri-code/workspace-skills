# Workspace skills

The skills Sound Dealer's clients use inside their own Claude: planning the day and the week, research, writing, music, visual design, finance, and the optional Social Studio and Writing packs.

## Add it once

In Claude, open Settings, then Plugins, add this store (`stefanoritteri-code/workspace-skills`) and switch on **Workspace skills**. It keeps itself up to date after that.

The skills work with the client's own workspace, which Sound Dealer sets up and supports.
