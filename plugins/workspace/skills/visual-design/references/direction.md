# Art direction

Retrieve live decisions, taste examples, rejected examples and later corrections. Establish object, audience, desired effect, formats, constraints, date and editable result. Use existing answers; a single crop should proceed directly. For a multi-format identity or campaign state the frame and unresolved choice before developing alternatives.

Learn the eye from a small set of liked references and, if available, one disliked reference with reasons. One image is enough for a provisional reading. Look at actual images; a title or inaccessible link is not vision. Without a visible file request an upload/export through the permitted route and label description-only work provisional.

Separate visible hierarchy, proportion, framing, light, color, type, space and texture from the owner's exact preference, our operational translation and uncertainty. Exact lenses, films or processes cannot be inferred from appearance. Translate “more elegant” into a visible test of margin, scale or contrast. Do not impose a palette, era, humor or minimalism. Production instructions describe elements rather than relying on an artist's reputation.

Use [visual-controls.md](visual-controls.md). Coordinate only needed roles: visual research explains the reference; design/type supplies hierarchy and adaptation; photography selects or specifies a needed image; writing supplies real message/voice; directing supplies sequence and duration; production names tools/inputs/output; review locates a defect and test. These are perspectives of one model, not people or agents actually summoned. If a meeting is requested, one attributed contribution per turn and wait. No staged debate for a small edit. Message-first work brings writing first.

Offer two directions only if they answer the brief differently; otherwise one. Each gives central idea, composition, image/text balance, color/type, observed reference, exclusions, risk and a visible proof. Recommend with a brief-based reason. Do not reconfirm an adopted direction, but do not cross an unresolved essential choice.

Name the actual route. The door stores text/acts, not image editing, layered originals, code execution or hosting. An exposed capable editor connector can perform only its authorized operations; otherwise deliver input files, exact operations, output specification and checks for a human editor/local builder. File visibility does not prove editor control. A prompt is not a made image.

Inspect the real object at use size: first focal point, readability, crop, cross-format coherence, factual text and adopted direction. Without preview, visual review remains open. Keep what works and rank concrete defects/remedies. Preserve before/after and exact corrections, distinguishing local taste from adopted future rules. In the next relevant work retrieve and test the correction, including its scope limit. Saving is not already demonstrated learning.

Use [landing.md](landing.md) for a Visual direction page with seen references, versions, reasons and limits, the exact adopted choice linked by `page`, and a chosen dated next step. State prepared/modified/verified/published separately. A direction choice alone does not authorize publication.
