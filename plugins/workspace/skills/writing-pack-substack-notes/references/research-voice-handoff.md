# Research, originality, voice, and handoff for Substack Notes

> Reference for writing-pack-substack-notes. Read when doing market research, guarding originality, or handing approved Notes over.

The editorial responsibility is deciding when each capability — web research, the owner's notes, the record — improves the work, and keeping sources, voice, and delivery distinct.

## Resolving sources

When the owner pastes a Substack Note URL, fetch and read the exact item before analysis. Read every Note that materially affects the finished portfolio. When several references are supplied, compare them structurally, then read the selected examples in full. A preview, screenshot, title, or engagement count is not a substitute for the source. If a page cannot be fetched, say so and ask them to paste the text.

When a creator is named without a link, search for them and ask for clarification only if multiple credible matches remain. When researching the market, search Substack Notes specifically, compare representative examples across authors, and do not infer a universal formula from one viral Note. There is no creator-baseline tool here: report engagement only as you read it on the page, and never present it as a multiple of a baseline you did not see.

## Evidence lanes

- **Owned source material** supports the owner's facts, opinions, experience, publication themes, and voice.
- **Live market research** supports claims about current reader interest, recurring formats, saturation, and unanswered questions.
- **Reference Notes** support observations about structure, rhythm, reader recognition, analogy, and conversation mechanics.

Show research receipts when external sources materially shape the editorial recommendation. Name only sources actually retrieved and explain what each contributed.

## Voice and originality

Their voice rules, writing samples and publication material determine identity. Reference authors do not. Never imitate a creator's signature phrases, personal stories, worldview, or distinctive cadence. Translate a mechanism into their own evidence and natural range.

Do not force all Notes into punchy fragments. Substack can reward reflective paragraphs, ordinary details, unresolved thought, and genuine questions. Keep claims proportional to evidence. Never invent a result, quote, link, newsletter, credential, or personal memory.

## Corrections

If the owner rejects a source, interpretation, tone, or claim, stop using it. Revise every affected Note rather than patching only the sentence the owner noticed. Preserve accepted Notes unchanged unless a portfolio-level change requires coordination.

## Handoff

Posting and scheduling are the owner's acts. After a complete approved portfolio, ask whether the owner wants a posting plan or tasks to post selected Notes on given days. Do not assume all six should go out.

- A posting plan is a short dated list in the chat: day, Note label, and its opening line.
- In the room, a task per selected Note can go on the board on their yes, with the exact approved text in the task's notes.
- Never treat keeping a Note as a page as permission to publish. Never rewrite text during handoff. Read back every receipt so the owner knows what was filed.
