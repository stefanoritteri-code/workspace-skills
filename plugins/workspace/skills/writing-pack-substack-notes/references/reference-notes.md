# Reference Notes — structural mechanisms

> Reference for writing-pack-substack-notes. Read when the owner wants to see a mechanism, or names one of these creators.

Six public Substack Notes chosen because each demonstrates one mechanism clearly. They teach FORM, never voice: borrow the mechanism, rebuild it from the owner's own material, and never reuse a phrase, image or cadence. Their full text is not kept here — when the exact wording matters, open the link and read it there. Engagement figures are as shown when the set was assembled (2026) and are not a baseline.

| Creator | Note | Mechanism it demonstrates |
|---|---|---|
| Dr. Dominic Ng (@drdominicng), 01/04/26 | https://substack.com/@drdominicng/note/c-236777098 — "be bored more often" | **Direct recommendation.** One short imperative, a run of five concrete ways to act on it, then a one-line personal payoff. The recommendation is earned by the ordinariness of the examples. |
| Dr. Dominic Ng (@drdominicng), 25/02/26 | https://substack.com/@drdominicng/note/c-219605040 — "meant to live slower" | **Poetic observation.** Lower-case accumulation of small, ordinary desires that resolves into a worldview and a shared longing ("the parts you'd miss"). No argument, all recognition. |
| FRIEND (@levelupwithfriend), 21/04/26 | https://substack.com/@levelupwithfriend/note/c-246815545 — "change the room to change the thought" | **Imperative, examples, mechanism.** Energetic command, four concrete places to go, a compressed cause-and-effect line (same environment, same thoughts), then the payoff of trying it. |
| The Stoic Manual (@stoicmanual), 08/07/26 | https://substack.com/@thestoicmanual/note/c-290361809 — "it is not about you" | **Emotional reframe.** Names the painful interpretation (they wronged me), replaces it with a more useful one (their acts come from their own fears), uses short fragments for cadence, ends on what changes for the reader. |
| Introvert's Intro (@introvertsintro), 12/04/26 | https://substack.com/@introvertsintro/note/c-242076810 — "signs of a loud mind" | **Identity recognition list.** A capitalised title naming a group, five independent, non-redundant behaviours that make the reader feel seen, then a follow CTA. The CTA is optional and never the default. |
| Julie Fratantoni, PhD (@drjuliefratantoni), 08/07/26 | https://substack.com/@drjuliefratantoni/note/c-290688158 — "the brain needs use, not only input" | **Analogy plus expertise.** A familiar system (muscles need use, not just protein) mapped onto the unfamiliar one (the brain), the implication stated plainly, then one line of credentials and what she writes about — a soft publication bridge. |

## How to use them

- Name the mechanism, not the author, when proposing a route: "an analogy-plus-insight Note from your point about your own trade" — not "a Julie Fratantoni-style Note".
- Test originality by removing the names: if the new Note would still read as recognizably theirs, it is not transformed enough.
